## v0.1.0-alpha.7 — 2026-10-14


Generated from Lingara API 2026-10-virile-dragon (supported) at spec backend@9781d04a1d3a8881e54d1210e63f555886bed518.

### Added

- Release tooling: `publish` now refuses unless the vendored spec's current version is the one the live API pins new clients to (`make check-release-current-version`). Tooling only; no kit changes.

### Changed

- Every kit depends on its language's `lingara` library from 0.2.0-alpha.1 (`LIBRARY_FLOOR`). The kits' earlier range stopped below 0.2, so an app that pinned the 0.2 library got a second, nested copy beside the kit's, and the kit verified signatures with a different library than the app called. The kits' own code is unchanged; `verifySignature` is the same in 0.2.0-alpha.1.
- The kits are generated for API version `2026-10-virile-dragon`, the version new clients are now pinned to, as the 0.2 library is (was `2026-10-affable-towhee`). The app schemas did not change between the two, so only each kit's generated-for version moves.
